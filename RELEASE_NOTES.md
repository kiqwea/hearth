Доступ для друзей теперь сначала без регистрации.

- По кнопке «Включить доступ для друзей» Hearth сначала сам открывает порт на роутере и показывает адрес, который друзья вводят в Minecraft. Никаких сайтов и аккаунтов.
- Такой адрес может меняться между запусками: Hearth всегда показывает актуальный.
- Если роутер или провайдер этого не позволяют, Hearth объяснит почему и предложит бесплатный playit.gg, как раньше.
- Если друзья не могут подключиться напрямую, на карточке сервера есть кнопка «Использовать playit».
