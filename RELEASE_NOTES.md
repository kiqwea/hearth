Доступ для друзей настраивается сам.

- Кнопка «Включить доступ для друзей» больше не нужна: при запуске сервера Hearth сам открывает порт на роутере и показывает адрес для друзей.
- Если роутер или провайдер этого не позволяют, Hearth предложит один раз войти в бесплатный playit.gg. После этого адреса выдаются сами для всех серверов.
- Убран адрес «В одной сети (Wi-Fi)»: друзья рядом подключаются по тому же адресу, что и все.
