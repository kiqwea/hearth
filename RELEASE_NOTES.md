Сборка модов для друзей.

- На вкладке «Моды» (Fabric) появилась «Сборка для друзей»: Hearth сам собирает моды, которые нужны игрокам, вместе с их зависимостями (например, Fabric API). Серверные оптимизации вроде Lithium в сборку не попадают: друзьям они не нужны.
- «Замена OptiFine» одной галочкой: Sodium, Iris (шейдеры), Entity Culling, ImmediatelyFast, FerriteCore — игра у друзей будет быстрее и красивее.
- «Скачать .mrpack» для Prism Launcher и Modrinth App: друг открывает файл, и лаунчер сам ставит Fabric и все моды. Если у сервера есть адрес для друзей, сервер сразу появится в списке серверов.
- «Скачать zip» для TLauncher и других лаунчеров: папка mods и понятная инструкция по установке.
